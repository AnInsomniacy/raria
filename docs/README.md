# raria Documentation

raria is a Rust-native download manager and daemon. Its public contract is the
native CLI, `raria.toml`, `/api/v1` HTTP JSON resources, `/api/v1/events`
WebSocket events, versioned native persistence, structured logs, release
archives, and native documentation.

Start here:

- [Support](SUPPORT.md) for questions, bug reports, and evidence handling.
- [Troubleshooting](TROUBLESHOOTING.md) for common CLI, daemon, API, transfer,
  and restore issues.
- [Integration](INTEGRATION.md) for native client and GUI integration.
- [Release Process](RELEASE.md) for versioning, local verification, tags, and
  GitHub Releases.
- [Release Integrity](RELEASE_INTEGRITY.md) for artifacts and checksum checks.

The modernization tracker in [core-modernization](core-modernization/overview.md)
