# Code of Conduct

## Standard

The raria project expects focused, respectful, technically grounded
participation. Discuss behavior, evidence, tradeoffs, and code. Do not harass,
insult, threaten, impersonate, publish private information, or derail technical
work with personal attacks.

## Scope

This applies to repository issues, pull requests, discussions, code review,
security reports, release work, and any public space where someone represents
the project.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and contributions that
violate this policy. Maintainers may also limit participation from users who
repeatedly ignore project scope, security process, or review standards.

## Reporting

For ordinary conduct problems, open a GitHub issue or contact the maintainer
through the repository. For private or security-sensitive reports, use GitHub
Security Advisories.
